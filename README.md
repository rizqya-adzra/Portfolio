
# Rizqya's Portfolio Website

A dynamic and responsive website showcasing Rizqya’s resume, skills, projects, and articles that highlight her diverse expertise. This platform serves as a hub to explore her diverse expertise in software development, design, and other creative skill sets.

## Features

- Light/dark mode toggle
- Switch between three languages 
- Responsive for all devices
- Animated Parallax Background
